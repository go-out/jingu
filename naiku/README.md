伊勢信仰の中心となる神宮の二所大神宮（2つの正宮（しょうぐう））の1つである「皇大神宮（こうたいじんぐう）」と10の別宮、27の摂社・16の末社・30の所管社（別宮が要する8の所管社）の92社

一般には「内宮（ないくう）」と呼ばれる、天照大神の神体「八咫鏡（やたのかがみ）」を奉安する「正宮」の宮域は、神宮を構成するすべての中で最も尊い「心のふるさと」と称される神域
（皇大神宮の宮域（宇治橋の内側）には、正宮のほかに2宮の別宮「荒祭宮・風日祈宮」や、30の所管社のうち第1位から第8位と第28位から第30位の11社、神宮の祭祀をはじめとするすべての事務を取り扱う神宮司庁（じんぐうしちょう）庁舎などがある）

* 10の別宮（2宮は正宮の宮域）のうち、5宮は正宮の宮域外「月讀宮・倭姫宮」の宮域、3宮は伊勢市外の「瀧原宮・伊雑宮」の宮域に鎮座する
* 27の摂社・16の末社は、伊勢市内（内宮を経由して伊勢湾に流れる「五十鈴川」の川辺付近や伊勢湾の海岸付近）、かつて神三郡と呼ばれた古代より神宮の経済的基盤となっていった地域のにあたる「度会郡の玉城町・度会町」に分布する（各鎮座地に古来より祀られる国魂神や、自然や田野・農耕を司る守護神を祀る）
* 30の所管社のうち、内宮にある11社以外は、松坂市にある2社の「機殿神社」と二見の「御塩殿神社」の宮域に鎮座する（そのほか、遙宮とも呼ばれる「瀧原宮・伊雑宮」それぞれの宮域には、それぞれの所管社がある）

（内宮の宮域内は右側通行）
