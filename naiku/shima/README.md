毎年 六月二十四日に三大御田植祭・国の重要無形民俗文化財「磯部の御神田」が行われる皇大神宮（内宮）の境外別宮、神田を持つ唯一の別宮（いざわのみや・いぞうぐう）の聖域

（古くから「磯部（いそべ）氏」と呼ばれる漁猟民（海人族）が暮らした地で、天照大神の古い原型は伊勢の漁民が奉じた男性太陽神だったとも考えられている）

伊雑宮の南西には、伊雑宮の外宮のように信仰される伊雑宮の所管社「佐美長神社」があり、二社を結ぶ参道「御幸道（ごこうみち）」は、神が両社を行き来する道と伝わる
（また、地元では道中に鎮座する伊雑宮の摂末社のような関係にある「磯部神社」と合わせて、三社詣でをする慣わしがある）
