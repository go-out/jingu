古代より神宮の経済的基盤となっていった、現在の松阪市東南部〜櫛田川下流周辺地域に相当する「飯野郡（いいの）」（鎌倉時代初期に飯高郡も加入）と、伊勢市と松阪市の間に位置する「多気郡（たき）」「度会郡（わたらい）」を合わせた「神三郡（または、三箇神郡）」
___

* 飯野郡には、元伊勢「飯野高宮」の比定地が点在するほか、天照大神の衣「神御衣（かんみそ）」を奉織する二社の内宮の所管社「機殿神社（はたどの）」がある（機織りの伝統技術と綿栽培業や藍染技術を融合させた「松坂木綿」を使った呉服等のアパレル商品展開こそが、後の江戸時代に松坂商人が成功した要因にもなった）
* 多気郡（古称は「竹郡」）には、元伊勢「佐佐牟江宮」の比定地が点在するほか、天皇に代わって伊勢神宮に仕えた未婚の皇女「斎王（さいおう）」が暮らした宮殿「斎宮（さいぐう・いつきのみや）」があった斎王の宮地
* 度会郡（現 玉城町・度会町）は、内宮の摂末社が多く分布する神宮の神領として深く関わる地

***

松坂市の北部（「嬉野町宮古」または「三雲町市場庄」周辺）には、京都から伊勢神宮の斎宮へ「斎王」の一行が下向する儀式「群行（ぐんこう）」が行わる際、最後に宿泊する仮の宮「一志頓宮」があったとされる
（群行は、近江国の国府と甲賀と垂水・伊勢国の鈴鹿と壱志に設けられた頓宮（とんぐう）で各一泊し、六日目に斎宮へ入る次第だったと伝わるが、実際の行程を語る史料はほとんど残っていない）
