日本国民の総氏神、全ての神社の上に立つ神社・神社本庁の本宗（ほんそう）である「神宮（じんぐう）」は、三重県伊勢市にある「内宮（ないくう）・外宮（げくう）」の通称で知られる2つの正宮「二所大神宮（皇大神宮・豊受大神宮）」と14の別宮、109の摂社・末社・所管社の合計125社から成り立つ集合体の総称

創祀は3世紀後半から4世紀前半、天照大神の神霊を込めた三種の神器の一つ「八咫鏡（やたのかがみ）」を鎮座する珠玉の地を求めて、崇神天皇（第10代、すじん）の皇女「豊鍬入姫命（とよすきいりひめのみこと）」〜 垂仁天皇（第11代、すいにん）の第四皇女「倭姫命（やまとひめのみこと）」が日本各地を巡った末、ついにたどり着いた現在地「神風吹く伊勢の五十鈴川のほとり（五十鈴宮）」が永遠の社に定められた

* 豊鍬入姫命が54年・倭姫命が34年（延べ88年）の長旅の中で一時的に天照大神を祀ったとされる場所は「元伊勢（もといせ）」と呼ばれ、全国には元伊勢の伝承を持つ場所が多数存在する（正確な場所はほとんど不明確）
