伊勢信仰の中心となる神宮の二所大神宮（2つの正宮（しょうぐう））の1つである「豊受大神宮（とようけだいじんぐう）」と4の別宮、6の摂社・8の末社・4の所管社の計33社

一般には「外宮（げくう）」と呼ばれる、御饌の神（食物・穀物を司る女神）「トヨウケビメ」を祀る「正宮」の宮域は、伊勢の中心にありながら自然が豊富に残された非日常空間を形成する神域
（豊受大神宮の宮域には、正宮のほかに3の別宮、2の摂末社・4の所管社（うち2社は一般参拝者立入不可）がある）

* 4の別宮のうち「月夜見宮」は正宮の宮域外にあり、外宮北御門から北へ伸びる参道は神が行き来する道「神路通 かみじどおり」と呼ばれる
* 鳥羽市にある1の末社を除く23の摂社・末社は、伊勢市内に分布（摂末社の多くは、明治初期まで伊勢豊受大神宮の神職を世襲していた「度会氏（わたらいうじ）」に関わる神々や、外宮の鎮座以前より度会郡に祀られていた国魂神とされる）

___

豊受大神宮（外宮）の創建は478年頃（雄略天皇22年）、天照大神から「自分への食事（お供え物）を司る神様を近くに呼んでほしい」との神託を得て、丹波国の比治の真奈井（ひじのまない）にいた「トヨウケビメ（豊受大神、豊宇気毘売神・等由気太神）」が現在地「伊勢国度会の度会郡沼木郷山田原」に呼び寄せられたと伝わる

* 「トヨウケビメ」は、古事記に登場するイザナミの尿から生まれた「ワクムスビ」の子と同一とされる
* 鎌倉時代末の伊勢神道では、造化三神の「天之御中主神（あめのみなかぬしのかみ）」と豊受大神を同一視し、これを始源神と位置づけている
